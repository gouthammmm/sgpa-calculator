# SGPA Calculator

A web-based SGPA calculator designed to calculate semester grade point averages using course grades and credit values.

## Technologies Used

* HTML
* CSS
* JavaScript

## Features

* Enter course credits and grades
* Calculate SGPA automatically
* Simple and user-friendly interface
* Web-based calculator

## Project Files

* `index.html` — Main webpage and calculator interface
* `main.js` — SGPA calculation logic
* `style.css` — Website styling and layout

## Objective

The project demonstrates the use of HTML, CSS, and JavaScript to build a functional web-based academic calculator.
